## iOSForge 上传说明
1. ZIP 根目录直接是 AltStore、SideStore、Shared、AltStore.xcodeproj 等文件。上传时项目名建议填写 `SideStore_ZH`，将全部内容放入 `sources/SideStore_ZH`。
2. 你的**个人 iOSForge 仓库根目录** `iosforge.toml` 请参考本压缩包 `iOSForge_根目录配置示例/iosforge.toml`，注意不要误认为项目内的配置会自动覆盖 iOSForge 仓库根配置。
3. 重点是 `kind = "app"`、`[build].prepare_script = "sources/SideStore_ZH/ci/iosforge_prepare.sh"`。这个脚本会先从 GitHub 拉取固定版本依赖并生成 CodeSigning.xcconfig。
4. 根据 `iOSForge_根目录配置示例/工作流修改方法.txt` 将 build-ipa 的 macOS 与 Xcode 调整为 macos-26 / Xcode 26.2（受 Actions 主机镜像可用性限制）。
5. iOSForge 网页选择 **IPA / unsigned / Release**，源码目录 `sources/SideStore_ZH`，工程 `sources/SideStore_ZH/AltStore.xcodeproj`，Scheme `SideStore`，Bundle ID 留空，启动构建。
6. 构建成功后得到 **未签名 IPA**，需要通过合适的签名工具/已有安装流程签名。

## 完整性与限制
- 全部主工程源代码包含在包中。
- Git 子模块**未离线打包**，由编译脚本联网下载。若不能访问 GitHub，仍会无法编译。
