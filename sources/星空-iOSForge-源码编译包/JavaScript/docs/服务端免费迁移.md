# 免费维护版需要后端配套的部分

这份文件依据客户端代码恢复接口要求，不是恢复出来的服务端源码。客户端缺少后端实现，不能自动替你在现有线上服务器部署免费规则。

| 协议 | 当前观察 | 免费测试服务器应实现 |
|---|---|---|
| `createShadow2` | 返回真实影子 ID 和资料 | 允许合法账号免费创建/切换影子，保留账号与风控限制 |
| `setPickup` | 可能返回 `needVip` | 移除会员收费判定，保留设置保存及真实错误 |
| `pickupBottle` | 可能返回 `insufficientStars`、余额及次数配额 | 免费返回实际内容；若保留次数/节流，明确它与收费的区别 |
| `shareReply` | 可能返回 `shadowExpired`、`vipExp`、`replyReject` | 取消仅与付费有关的影子聊天拒绝，保留拉黑、双方关系、青少年模式与发送限制 |
| `userConnConfirmed` | 同步余额/影子/到期状态 | 返回一致的免费权益状态，不再要求购买 |
| `viewSnap` | 原版查看图片可能扣星币，并推进消息状态 | 生产免费版应不扣费且保持真实已读/消息通知；当前客户端维护版默认仅本地预览，暂不调用此协议 |
| `sendStar` | 服务器维护星币账本 | 当前免费客户端已移除赠星币入口；如要保留赠礼功能，需要独立定义免费的实际服务端行为 |
| `verifyPurchase`、`purchaseAction` | 原内购验证和交易日志 | 免费客户端不再发送；恢复内购时再接回真实 Apple 验证及权益发放 |

接口字段和调用原文可参考上一份分析证据包的 contracts JSON。没有后端源码或可控的测试服务器时，仍可能出现“免费客户端已经放开，但服务器拒绝”的情况，不能将拒绝回包直接改成成功，因为真实消息、身份、文件和余额均不会因此在服务器产生。

后续可以先验证不依赖收费后端的页面、普通聊天和媒体路径，再对上述协议逐项接回免费服务器。真机测试记录应注明签名、实际 JS 版本、账号、服务器环境和操作结果，避免把旧热更新包的行为误认为恢复工程的行为。
