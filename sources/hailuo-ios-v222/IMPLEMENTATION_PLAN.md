# 海螺 iOS 15+ 原生版实施计划

## 不可突破的边界

- Android 源项目 `HailuoAndroid` 与现有后端只读，不修改文件、接口或数据。
- iOS 只写入 `HailuoiOS`，继续复用当前后端 API。
- 最低系统 iOS 15；使用 Swift 6、SwiftUI 与必要的 UIKit 桥接。
- iOS 26 及以后只使用 Apple 标准导航栏、标签栏、工具栏和弹窗提供的原生 Liquid Glass；iOS 15–25 使用系统材质兼容外观。
- Windows 阶段只完成代码、资源、契约检查和文档；Swift 编译、签名、真机测试及 IPA 导出必须在 Mac/Xcode 完成。

## 2026-09-30 对照修订

- 对照 Android 当前 `LoginScreen`、`NotificationSettingsScreen`、`AdminHomeScreen` 和 `/api/ws/kick` 事件格式后，修正了先前将多项 iOS 页面标为“已完成”的过度表述。
- 已补入按配置开放微信/QQ OAuth、通知偏好页、独立管理员认证，以及 MESSAGE/RECALL 实时刷新。
- 继续对照后将语音播放改为单实例状态管理（可停止/切换，播放结束或离开聊天页释放），并为录音加入上滑取消、权限等待松手保护和 60 秒自动停止；最近消息同步补入进度、结果摘要、账号切换中止和本地删除记录保护；为支付/同步响应增加模型解码测试。
- 按平台差异改用 iOS 原生导航栈：iOS 16+ 使用 `NavigationStack`，iOS 15 保留 `NavigationView`；iOS 26+ 不覆写系统栏以保留 Liquid Glass，iOS 15–25 用系统 blur material 作为兼容层。
- 继续对照后补入好友详情、最近消息同步、阅后图片查看会话关闭、VIP 同步范围说明、服务端动态支付目录、后台用户分页和消息保留策略设置；服务端支付目录可读取展示，但未接入 iOS 支付 SDK / StoreKit 及验单前不创建订单。
- 按用户确认补入 Google 境外入口显隐：用户同意隐私后仅查询公网出口 IP 国家码，CN 隐藏、其他有效国家代码显示，未知或失败默认隐藏；GeoIP 服务及 VPN 影响写入隐私说明。Google 登录仅留好 idToken 请求构造点，不调用未联调接口；QQ/微信继续按服务端启用配置开放。
- 隐私同意现在先于认证配置、GeoIP 和已登录会话恢复请求；支付套餐行不再表现为可购买按钮，APNs 页面说明 token 只保存在本机、后端注册未接入。后端后续接入要求集中记录于 `INTEGRATION_HANDOFF.md`。
- Android/后端目录保持只读。现有后端源码未见 APNs 设备令牌注册接口，因此 iOS 后台/锁屏推送不能仅靠客户端完整复刻；需要后端任务单独批准后再接入。
- 为修复 iOSForge 在 `Find projects` 阶段找不到工程的问题，源码包新增 `Hailuo.xcodeproj` 与共享 `Hailuo` Scheme；上传 ZIP 根目录直接放工程内容，并由静态检查防止遗漏工程文件。
- 当前仍没有 Xcode 编译、签名、IPA 导出或真机验证结果；Windows 文本检查不能替代这些验收。Google/QQ/微信服务端身份验证、StoreKit 验单、APNs 设备注册和真机媒体行为仍是完整 1:1 验收的未结项，不把静态通过宣称为功能全部完成。

## 实施顺序

1. 每次先从 Android 当前源码重新生成差异清单，不依据旧截图或旧接口记忆。
2. 先修会导致请求失败、错误扣费、越权或数据破坏的问题。
3. 再修页面结构、状态流、确认弹窗、空态和刷新行为。
4. 最后处理动画、间距、相对时间、辅助功能和系统版本差异。
5. 每轮运行静态检查和契约测试；Mac 上运行真实 Swift 编译后，逐条清零编译诊断。

## 平台差异处理原则

- Android APK 更新接口不能用于 iOS；iOS 更新只走 TestFlight、App Store 或受控 IPA 分发页。
- 后端未提供微信/QQ 路由，Google 又要求真实 `idToken`；iOS 禁止模拟登录，未配置时只显示明确提示。
- 公开 App Store 的数字内容和虚拟货币必须按 Apple 规则接 StoreKit。由于本任务禁止改后端，现有支付能力只原样保留给受控分发测试，并在交付文档中标出上架风险。
- 自动反向地理编码会把精确位置发给第三方地图服务；未获得产品与隐私授权前，只允许用户手动填写位置说明。
