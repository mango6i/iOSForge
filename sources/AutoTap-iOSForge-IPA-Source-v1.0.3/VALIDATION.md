# 1.0.3 手势显示、桌面快捷操作与锁屏回归验收

## 构建

保持 `AutoTap.xcodeproj` / `AutoTap` Scheme，最低系统 15.0，版本号与内部构建号均为 1.0.3。iOSForge 选择 IPA、unsigned；不应选择 dylib 或 Theos。

沿用原 1.0.3 的 TrollStore 安装方式，检查可执行文件保留 HID event-dispatch / event-monitor / event-filter 权限。勿二次普通自签。本包不包含新版越狱巨魔适配，不扩大安装范围。

## 真机必测（尚未执行）

编译后的 IPA 必须包含 `UIApplicationSceneManifest`（单场景、配置由 SwiftUI 场景代理提供）以及四个 `UIApplicationShortcutItems`，不能只检查菜单是否出现。覆盖安装后先完全关闭旧应用进程，再分别测试冷启动与后台恢复，勿删除应用数据。

0. 从桌面长按 AutoTap，确认四个快捷项。杀掉应用后和后台已启动时分别打开每项：单点、多点应显示对应悬浮窗待命；录制脚本与手势脚本应打开各自列表，空列表也可正常进入，不能自动回放。连续点击同一个单点/多点快捷项不应反向关闭悬浮窗。
1. 单点、多点、点击录制、手势录制分别首次开启、关闭，再快速交替开关至少 20 次；悬浮窗类型与脚本不能串台。
2. 软件内、软件外各连续录制至少 20 个点击，数字必须连续完整显示。点击与滑动脚本都检查回放位置和顺序。
3. 每种模式运行及空闲悬浮窗状态都测试手动锁屏与自然锁屏。先用短脚本/较慢间隔，在非重要操作页面测试。锁屏后不可继续注入触摸，应能正常亮屏和解锁；回到 AutoTap 保持暂停，点继续后才恢复。
4. 特别在长按或滑动中途锁屏，验证没有残留按下的手指；重复至少 10 次，并测试快速锁屏再解锁。
5. 暂停、立即继续、关闭，再开启别的模式；检查没有抬手中断新脚本、倒计时卡住、设置打不开或旧数字残影。
6. 在后台播放其他音频、模拟音频会话中断后检查安全暂停；回来后能够手动继续。不得以持续后台播放替代锁屏暂停。
7. 在原先正常使用 1.0.3 的 TrollStore 设备上执行以上步骤，并记录锁屏、解锁及暂停继续的实际结果。
8. 软件内、软件外分别录制“点击—弯曲滑动—点击—滑动—点击”：录制时点击目标应立即显示，滑动跟随手指显示完整轨迹；保存并重新开启脚本后点击编号应为 1、3、5，两个滑动不能显示为数字。点击录制仍应连续显示 1、2、3……，不存在相互串台。
9. 打开已保存的手势脚本、暂停及恢复、编辑返回、关闭再开启、旋转屏幕；检查静态轨迹和点击编号保留，运行时仅当前滑动轨迹动画，不出现重复的整条轨迹回放。

任何无法解锁、输入无响应或明显卡顿都应停止使用本构建，保留系统版本、设备型号、越狱/安装器版本、发生步骤和设备崩溃/卡顿日志；不要在缺少日志时声称全部修复或全机型已验证。
