    没有 Token？跟着步骤获取

    先建立自己的构建仓库，再创建只授权该仓库的 Token。它不是 GitHub 登录密码。

    1. 打开下方预填页面，确认登录的是你自己的 GitHub 账号。
    2. 选择 Only select repositories，仅勾选你自己的构建仓库。
    3. 确认仓库权限 Actions 和 Contents 都为 Read and write。
    4. 点 Generate token，复制生成的字符，切回本页粘贴后点“检查我的仓库”。
    打开预填创建页面（仍需确认）↗还没有自己的仓库？从这里开始 ↗查看完整 Token 教程 ↗已有 Token 报权限错误？按这里补齐 ↗

    不会预填网站作者的账号，也不会自动创建或读取你的令牌。令牌仅在本页内存中使用；不要发给 AI 或截图分享。
